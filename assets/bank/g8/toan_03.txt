# Chương VI. Phân thức đại số

## Bài 21. Phân thức đại số
?1 Phân thức đại số là biểu thức có dạng A/B, trong đó:
+ A, B là đa thức và B khác đa thức 0
- A, B là số tự nhiên
- B có thể bằng 0
- A phải khác 0
= Định nghĩa.
?1 Điều kiện xác định của phân thức 3/(x − 2) là:
+ x ≠ 2
- x ≠ 0
- x ≠ 3
- x ≠ −2
= Mẫu khác 0.
?1 Hai phân thức A/B và C/D bằng nhau nếu:
+ A · D = B · C
- A · C = B · D
- A = C
- A + D = B + C
= Định nghĩa bằng nhau.
?1 Giá trị của phân thức (x + 1)/(x − 1) tại x = 3 là:
+ 2
- 1
- 4
- 1/2
= 4/2.
?2 Điều kiện xác định của (x + 1)/(x² − 4) là:
+ x ≠ 2 và x ≠ −2
- x ≠ 2
- x ≠ 4
- x ≠ −1
= x² − 4 ≠ 0.
?2 Phân thức nào bằng (x − 1)/(x + 1)?
+ (x² − 1)/(x + 1)²
- (x − 1)²/(x + 1)
- (x + 1)/(x − 1)
- x/(x + 2)
= (x − 1)(x + 1)/(x + 1)².
?2 Phân thức 2x/(x² + 1) xác định khi:
+ với mọi x
- x ≠ 1
- x ≠ −1
- x ≠ 0
= x² + 1 > 0.
?3 Tìm x để phân thức (x − 3)/(x + 5) có giá trị bằng 0.
+ x = 3
- x = −5
- x = 0
- x = 5
= Tử bằng 0, mẫu khác 0.
?3 Tìm x để phân thức (x² − 9)/(x − 3) có giá trị bằng 0.
+ x = −3
- x = 3
- x = ±3
- không có x
= x = 3 làm mẫu bằng 0 nên loại.
?3 Đa thức A thỏa mãn A/(x + 2) = (x² − 4)/(x − 2) (x ≠ ±2) là:
+ (x + 2)²
- x² − 4
- x + 2
- (x − 2)²
= A = (x + 2)(x − 2)(x + 2)/(x − 2).
?4 Giá trị lớn nhất của phân thức 3/(x² + 1) là:
+ 3, khi x = 0
- 1
- 0
- không có
= Mẫu nhỏ nhất bằng 1.
?4 Tìm số nguyên x để 4/(x − 1) nhận giá trị nguyên.
+ x ∈ {−3; −1; 0; 2; 3; 5}
- x ∈ {2; 3; 5}
- x ∈ {0; 2}
- x ∈ {−1; 1; 2; 4}
= x − 1 ∈ {±1; ±2; ±4}.

## Bài 22. Tính chất cơ bản của phân thức đại số
?1 Nhân cả tử và mẫu của phân thức với cùng một đa thức khác 0 thì:
+ được phân thức bằng phân thức đã cho
- phân thức tăng gấp đôi
- phân thức bằng 0
- phân thức đổi dấu
= Tính chất cơ bản.
?1 Rút gọn 6x²y/(9xy²).
+ 2x/(3y)
- 2/3
- 3x/(2y)
- 2xy/3
= Chia tử và mẫu cho 3xy.
?1 Quy tắc đổi dấu: A/B bằng:
+ (−A)/(−B)
- −A/B
- A/(−B)
- B/A
= Đổi dấu cả tử và mẫu.
?1 Rút gọn (x² − 1)/(x + 1).
+ x − 1
- x + 1
- x² − 1
- 1
= (x − 1)(x + 1)/(x + 1).
?2 Rút gọn (x² + 2x + 1)/(x² − 1).
+ (x + 1)/(x − 1)
- (x − 1)/(x + 1)
- 1
- x + 1
= (x + 1)²/[(x − 1)(x + 1)].
?2 Rút gọn (3x − 6)/(x² − 4).
+ 3/(x + 2)
- 3/(x − 2)
- 3
- (x − 2)/3
= 3(x − 2)/[(x − 2)(x + 2)].
?2 Mẫu thức chung của 1/(x − 1) và 1/(x + 1) là:
+ x² − 1
- x − 1
- 2x
- x² + 1
= (x − 1)(x + 1).
?3 Rút gọn (x³ − 8)/(x² + 2x + 4).
+ x − 2
- x + 2
- x² − 4
- 1
= Hiệu hai lập phương.
?3 Rút gọn (2 − x)/(x² − 4).
+ −1/(x + 2)
- 1/(x + 2)
- 1/(x − 2)
- −1/(x − 2)
= 2 − x = −(x − 2).
?3 Mẫu thức chung của 1/(2x) và 1/(3x²) là:
+ 6x²
- 6x
- 5x²
- 6x³
= BCNN của 2, 3 và lũy thừa cao nhất x².
?4 Rút gọn (x² − xy)/(y² − xy).
+ −x/y
- x/y
- −y/x
- 1
= x(x − y)/[y(y − x)].
?4 Rút gọn (x⁴ − 1)/(x³ + x).
+ (x² − 1)/x
- x − 1
- (x² + 1)/x
- x
= (x² − 1)(x² + 1)/[x(x² + 1)].

## Bài 23. Phép cộng và phép trừ phân thức đại số
?1 Tính 2/x + 3/x.
+ 5/x
- 5/(2x)
- 6/x
- 5/x²
= Cùng mẫu: cộng tử.
?1 Tính x/(x + 1) + 1/(x + 1).
+ 1
- x/(x + 1)
- (x + 1)/(2x + 2)
- 2
= (x + 1)/(x + 1).
?1 Tính 5/(x − 2) − 3/(x − 2).
+ 2/(x − 2)
- 8/(x − 2)
- 2
- 2/(2x − 4)
= Trừ tử, giữ mẫu.
?1 Phân thức đối của 2/(x − 1) là:
+ −2/(x − 1)
- 2/(1 + x)
- (x − 1)/2
- 2/(x + 1)
= Tổng bằng 0.
?2 Tính 1/x + 1/(x + 1).
+ (2x + 1)/[x(x + 1)]
- 2/(2x + 1)
- 1/[x(x + 1)]
- (x + 1)/x
= Quy đồng mẫu.
?2 Tính 1/(x − 1) − 1/(x + 1).
+ 2/(x² − 1)
- −2/(x² − 1)
- 0
- 2x/(x² − 1)
= (x + 1 − x + 1)/(x² − 1).
?2 Tính x/(x − y) + y/(y − x).
+ 1
- 0
- (x + y)/(x − y)
- −1
= (x − y)/(x − y).
?3 Tính 1/(x² − 4) + 1/(x + 2).
+ (x − 1)/(x² − 4)
- 2/(x² − 4)
- (x + 1)/(x² − 4)
- 1/(x − 2)
= (1 + x − 2)/(x² − 4).
?3 Tính 2x/(x² − 1) − 1/(x − 1).
+ 1/(x + 1)
- 1/(x − 1)
- (x + 1)/(x² − 1)
- x/(x² − 1)
= (2x − x − 1)/(x² − 1) = (x − 1)/(x² − 1).
?3 Tính 3/(2x) + 1/(3x).
+ 11/(6x)
- 4/(5x)
- 4/(6x)
- 1/x
= 9/(6x) + 2/(6x).
?4 Rút gọn 1/[x(x + 1)] + 1/[(x + 1)(x + 2)].
+ 2/[x(x + 2)]
- 1/[x(x + 2)]
- 2/(x + 1)
- 1/x
= (1/x − 1/(x+1)) + (1/(x+1) − 1/(x+2)) = 1/x − 1/(x + 2).
?4 Tìm a, b sao cho 1/(x² − 1) = a/(x − 1) + b/(x + 1).
+ a = 1/2, b = −1/2
- a = 1, b = −1
- a = −1/2, b = 1/2
- a = 1/2, b = 1/2
= a(x + 1) + b(x − 1) = 1 → a + b = 0, a − b = 1.

## Bài 24. Phép nhân và phép chia phân thức đại số
?1 Tính (2x/3) · (9/x²).
+ 6/x
- 18/(3x)²
- 6x
- 2/(3x)
= 18x/(3x²).
?1 Phân thức nghịch đảo của (x + 1)/(x − 2) là:
+ (x − 2)/(x + 1)
- −(x + 1)/(x − 2)
- (x + 1)/(x + 2)
- 1
= Đảo tử và mẫu.
?1 Tính (x/y) : (x²/y²).
+ y/x
- x/y
- x³/y³
- 1
= (x/y) · (y²/x²).
?1 Muốn chia A/B cho C/D (C/D ≠ 0) ta:
+ nhân A/B với D/C
- nhân A/B với C/D
- chia tử cho tử
- cộng hai phân thức
= Quy tắc chia.
?2 Tính [(x² − 1)/x] · [x²/(x + 1)].
+ x(x − 1)
- x(x + 1)
- x − 1
- x²
= (x − 1)(x + 1) · x²/[x(x + 1)].
?2 Tính [(x + 2)/(x − 3)] : [(x² − 4)/(x − 3)].
+ 1/(x − 2)
- x − 2
- 1/(x + 2)
- (x + 2)²
= (x + 2)/(x² − 4).
?2 Tính (3x²/(4y)) · (8y²/(9x)).
+ 2xy/3
- 2x/(3y)
- 24xy/36
- 3xy/2
= 24x²y²/(36xy).
?3 Rút gọn [(x² − 4)/(x² + 4x + 4)] : [(x − 2)/(x + 2)].
+ 1
- x − 2
- (x + 2)²
- (x − 2)/(x + 2)
= [(x − 2)(x + 2)/(x + 2)²] · [(x + 2)/(x − 2)].
?3 Tính (1 − 1/x) · x/(x − 1) với x ≠ 0, x ≠ 1.
+ 1
- x
- x − 1
- 1/x
= (x − 1)/x · x/(x − 1).
?3 Tính (x³ + 1)/(x² − x + 1) · 1/(x + 1).
+ 1
- x + 1
- x² + 1
- x
= Tổng hai lập phương.
?4 Rút gọn (1 + 1/x)(1 + 1/(x + 1))(1 + 1/(x + 2)).
+ (x + 3)/x
- 1
- (x + 1)/x
- x/(x + 3)
= [(x+1)/x] · [(x+2)/(x+1)] · [(x+3)/(x+2)].
?4 Giá trị của biểu thức [x/(x − 1) − 1] · (x − 1) với x ≠ 1 là:
+ 1
- x
- 0
- x − 1
= [x − (x − 1)]/(x − 1) · (x − 1) = 1.

# Chương VII. Phương trình bậc nhất và hàm số bậc nhất

## Bài 25. Phương trình bậc nhất một ẩn
?1 Phương trình bậc nhất một ẩn có dạng:
+ ax + b = 0 (a ≠ 0)
- ax² + b = 0
- a/x + b = 0
- ax + b = 0 với a = 0
= Định nghĩa.
?1 Phương trình nào là phương trình bậc nhất một ẩn?
+ 2x − 3 = 0
- x² + 1 = 0
- 0x + 2 = 0
- 1/x = 2
= Dạng ax + b = 0, a ≠ 0.
?1 Nghiệm của phương trình 3x − 6 = 0 là:
+ x = 2
- x = −2
- x = 3
- x = 6
= 3x = 6.
?1 Phương trình ax + b = 0 (a ≠ 0) có:
+ một nghiệm duy nhất x = −b/a
- vô nghiệm
- vô số nghiệm
- hai nghiệm
= Nghiệm duy nhất.
?2 Giải phương trình 5x + 2 = 3x − 4.
+ x = −3
- x = 3
- x = −1
- x = 1
= 2x = −6.
?2 Giải phương trình 2(x − 1) = x + 3.
+ x = 5
- x = 1
- x = −5
- x = 4
= 2x − 2 = x + 3.
?2 x = 2 là nghiệm của phương trình nào?
+ 3x − 1 = 5
- 2x + 1 = 3
- x − 2 = 1
- 4x = 2
= 6 − 1 = 5.
?3 Giải phương trình (x − 1)/2 + x/3 = 2.
+ x = 3
- x = 2
- x = 6
- x = 1
= 3(x − 1) + 2x = 12 → 5x = 15.
?3 Giải phương trình (2x + 1)/3 − (x − 1)/2 = 1.
+ x = 1
- x = −1
- x = 5
- x = 3
= 2(2x + 1) − 3(x − 1) = 6 → x + 5 = 6.
?3 Tìm m để phương trình (m − 2)x + 3 = 0 là phương trình bậc nhất.
+ m ≠ 2
- m = 2
- m ≠ 0
- m = 0
= Hệ số của x khác 0.
?4 Tìm m để phương trình 2x + m = x − 1 có nghiệm x = 3.
+ m = −4
- m = 4
- m = −2
- m = 2
= 6 + m = 2.
?4 Phương trình x + 1 = x + 2 có:
+ vô nghiệm
- một nghiệm
- vô số nghiệm
- hai nghiệm
= Thu gọn: 0x = 1.

## Bài 26. Giải bài toán bằng cách lập phương trình
?1 Bước đầu tiên khi giải bài toán bằng cách lập phương trình là:
+ chọn ẩn và đặt điều kiện cho ẩn
- giải phương trình
- kết luận
- kiểm tra nghiệm
= Các bước giải.
?1 Tổng hai số là 50, số này hơn số kia 10. Số lớn là:
+ 30
- 20
- 25
- 40
= x + (x − 10) = 50 → x = 30.
?1 Một số cộng 7 rồi nhân 2 được 30. Số đó là:
+ 8
- 11
- 15
- 23
= 2(x + 7) = 30.
?1 Tuổi bố gấp 3 lần tuổi con, tổng tuổi hai bố con là 48. Tuổi con là:
+ 12
- 16
- 36
- 24
= 4x = 48.
?2 Một xe đi từ A đến B với vận tốc 40 km/h, lúc về 50 km/h, tổng thời gian 4,5 giờ. Quãng đường AB là:
+ 100 km
- 90 km
- 120 km
- 80 km
= x/40 + x/50 = 4,5 → 9x/200 = 4,5.
?2 Hình chữ nhật có chiều dài hơn chiều rộng 5 m, chu vi 50 m. Chiều rộng là:
+ 10 m
- 15 m
- 12,5 m
- 20 m
= 2(x + x + 5) = 50.
?2 Lớp có 40 học sinh, số nam bằng 3/5 số nữ. Số nữ là:
+ 25
- 15
- 24
- 16
= x + 3x/5 = 40 → x = 25.
?3 Hai vòi cùng chảy đầy bể trong 6 giờ, riêng vòi 1 chảy đầy bể trong 10 giờ. Riêng vòi 2 chảy đầy bể trong:
+ 15 giờ
- 4 giờ
- 16 giờ
- 8 giờ
= 1/x = 1/6 − 1/10 = 1/15.
?3 Mua 3 kg táo và 2 kg cam hết 210 000 đồng; giá 1 kg táo hơn 1 kg cam 20 000 đồng. Giá 1 kg cam là:
+ 30 000 đồng
- 50 000 đồng
- 40 000 đồng
- 35 000 đồng
= 3(x + 20 000) + 2x = 210 000 → 5x = 150 000.
?3 Một người gửi tiết kiệm, sau 1 năm nhận cả gốc lẫn lãi 106 triệu đồng với lãi suất 6%/năm. Số tiền gửi ban đầu là:
+ 100 triệu
- 99,64 triệu
- 106 triệu
- 94 triệu
= 1,06x = 106.
?4 Một ca nô xuôi dòng từ A đến B hết 4 giờ, ngược dòng hết 5 giờ. Vận tốc dòng nước 2 km/h. Quãng đường AB là:
+ 80 km
- 40 km
- 90 km
- 72 km
= 4(v + 2) = 5(v − 2) → v = 18; AB = 80.
?4 Một số tự nhiên có hai chữ số, chữ số hàng chục gấp đôi chữ số hàng đơn vị. Nếu đổi chỗ hai chữ số thì được số mới nhỏ hơn số cũ 36. Số đó là:
+ 84
- 42
- 63
- 21
= Số 21b; 21b − 12b = 9b = 36 → b = 4.

## Bài 27. Khái niệm hàm số và đồ thị của hàm số
?1 Đại lượng y là hàm số của x nếu:
+ mỗi giá trị của x xác định được duy nhất một giá trị của y
- mỗi x có hai giá trị y
- y không phụ thuộc x
- x và y bằng nhau
= Định nghĩa hàm số.
?1 Cho hàm số y = 2x + 1. Giá trị của y tại x = 3 là:
+ 7
- 6
- 5
- 8
= 2 · 3 + 1.
?1 Mặt phẳng tọa độ Oxy có trục hoành là:
+ Ox
- Oy
- O
- đường phân giác
= Trục nằm ngang.
?1 Điểm M(2; −3) có hoành độ là:
+ 2
- −3
- 0
- −1
= Hoành độ viết trước.
?2 Điểm nào thuộc đồ thị hàm số y = x²?
+ (−2; 4)
- (2; −4)
- (4; 2)
- (−2; −4)
= (−2)² = 4.
?2 Điểm A(−1; 2) nằm ở góc phần tư thứ:
+ II
- I
- III
- IV
= Hoành độ âm, tung độ dương.
?2 Cho f(x) = 3 − x. f(−2) bằng:
+ 5
- 1
- −5
- −1
= 3 − (−2).
?3 Đồ thị hàm số y = ax đi qua điểm (2; 6). Hệ số a là:
+ 3
- 12
- 1/3
- 4
= 6 = 2a.
?3 Điểm nằm trên trục tung có hoành độ bằng:
+ 0
- 1
- tung độ
- −1
= Dạng (0; b).
?3 Cho hàm số y = f(x) = x² − 1. Giá trị x để f(x) = 3 là:
+ x = 2 hoặc x = −2
- x = 2
- x = 4
- x = √2
= x² = 4.
?4 Cho A(1; 2), B(4; 6). Độ dài đoạn AB là:
+ 5
- 7
- √7
- 25
= √(3² + 4²).
?4 Hàm số y = f(x) có f(x + 1) = 2x + 3. Giá trị f(5) là:
+ 11
- 13
- 9
- 10
= x + 1 = 5 → x = 4; 2 · 4 + 3.

## Bài 28. Hàm số bậc nhất và đồ thị của hàm số bậc nhất
?1 Hàm số bậc nhất có dạng:
+ y = ax + b (a ≠ 0)
- y = ax² + b
- y = a/x
- y = b
= Định nghĩa.
?1 Hàm số nào là hàm số bậc nhất?
+ y = 2 − 3x
- y = x² + 1
- y = 1/x + 2
- y = 5
= a = −3 ≠ 0.
?1 Đồ thị hàm số y = ax + b (a ≠ 0) là:
+ một đường thẳng
- một đường cong parabol
- một đường tròn
- một điểm
= Đường thẳng.
?1 Đồ thị hàm số y = 2x + 3 cắt trục tung tại điểm:
+ (0; 3)
- (3; 0)
- (0; 2)
- (−3/2; 0)
= x = 0 → y = 3.
?2 Đồ thị hàm số y = 2x − 4 cắt trục hoành tại điểm:
+ (2; 0)
- (−2; 0)
- (0; −4)
- (4; 0)
= y = 0 → x = 2.
?2 Hàm số y = (m − 1)x + 2 là hàm số bậc nhất khi:
+ m ≠ 1
- m = 1
- m ≠ 0
- m ≠ 2
= Hệ số a ≠ 0.
?2 Điểm nào thuộc đồ thị y = −x + 1?
+ (2; −1)
- (2; 1)
- (−1; −2)
- (0; −1)
= −2 + 1 = −1.
?3 Đồ thị y = ax + 1 đi qua A(2; 5). Giá trị a là:
+ 2
- 3
- 1/2
- 4
= 5 = 2a + 1.
?3 Hàm số y = ax + b có đồ thị đi qua (0; −2) và (1; 1). Hàm số là:
+ y = 3x − 2
- y = −2x + 1
- y = x − 2
- y = 2x − 2
= b = −2; a + b = 1.
?3 Hàm số y = −2x + 5 đồng biến hay nghịch biến?
+ nghịch biến
- đồng biến
- không đổi
- không xác định
= a < 0.
?4 Diện tích tam giác tạo bởi đường thẳng y = 2x − 4 và hai trục tọa độ là:
+ 4
- 8
- 2
- 16
= Cắt Ox tại (2; 0), Oy tại (0; −4): S = 2 · 4 : 2.

- y = 12 000x
