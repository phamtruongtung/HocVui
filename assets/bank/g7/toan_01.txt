# Chương I. Số hữu tỉ

## Bài 1. Tập hợp các số hữu tỉ
?1 Số hữu tỉ là số viết được dưới dạng:
+ a/b với a, b ∈ ℤ, b ≠ 0
- a/b với a, b ∈ ℕ
- a/b với b = 0
- √a
= Định nghĩa số hữu tỉ.
?1 Tập hợp các số hữu tỉ kí hiệu là:
+ ℚ
- ℤ
- ℕ
- ℝ
= ℚ (Quotient).
?1 Số nào KHÔNG phải số hữu tỉ?
+ √2
- −3/4
- 0,5
- 7
= √2 là số vô tỉ.
?1 Số đối của −2/5 là:
+ 2/5
- −5/2
- 5/2
- −2/5
= Tổng hai số đối bằng 0.
?2 So sánh −3/4 và −2/3.
+ −3/4 < −2/3
- −3/4 > −2/3
- −3/4 = −2/3
- Không so sánh được
= −9/12 < −8/12.
?2 Số hữu tỉ nào lớn nhất: −0,5; 1/3; −1/4; 0,3?
+ 1/3
- 0,3
- −1/4
- −0,5
= 1/3 ≈ 0,333 > 0,3.
?2 Điểm biểu diễn số −3/2 trên trục số nằm:
+ giữa −2 và −1
- giữa −1 và 0
- giữa 1 và 2
- tại −3
= −3/2 = −1,5.
?3 Tìm số nguyên x để x/3 là số hữu tỉ âm lớn hơn −1.
+ x ∈ {−2; −1}
- x ∈ {−3; −2; −1}
- x ∈ {0; 1; 2}
- x ∈ {−2; −1; 0}
= −1 < x/3 < 0 → −3 < x < 0.
?3 Sắp xếp −1,2; 3/4; −5/4; 0 theo thứ tự tăng dần:
+ −5/4; −1,2; 0; 3/4
- −1,2; −5/4; 0; 3/4
- 0; −1,2; −5/4; 3/4
- −5/4; 0; −1,2; 3/4
= −5/4 = −1,25 < −1,2.
?3 Có bao nhiêu số nguyên nằm giữa −7/2 và 5/3?
+ 5
- 4
- 6
- 3
= −3,5 < x < 1,67: x ∈ {−3; −2; −1; 0; 1}.
?4 Cho a/b > 0 với a, b ∈ ℤ, b ≠ 0. Khẳng định nào đúng?
+ a và b cùng dấu
- a và b trái dấu
- a = 0
- b < 0 và a > 0
= Thương dương khi tử và mẫu cùng dấu.
?4 Tìm số hữu tỉ x biết x nằm giữa 1/5 và 1/4 và có mẫu bằng 40.
+ 9/40
- 7/40
- 11/40
- 10/40
= 1/5 = 8/40, 1/4 = 10/40; số ở giữa là 9/40.
